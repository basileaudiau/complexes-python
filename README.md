>Voici un projet que j'ai fait avec l'objectif de réviser les formules des nombres complexes.
>Je l'ai fait suite a un cours de NSI sur la POO (Programmation Orientée Objet) en Python.

Dans le code on a:
- Une **classe** `Complexe`, elle permet de gérer des affixes
- Dans cette **classe** j'ai codé les formules du chapitre sur les nombres complexes sous forme **methodes**
- Une **méthode magique** (`__str__`) pour afficher un affixe naturellement avec le 'i' qui apparait
- Une **importation** des fonctions `atan2` et `sqrt` de la bibliothèque `math`
